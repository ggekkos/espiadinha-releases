# Segurança / Security

## Como avisar sobre um problema de segurança
Achou um jeito de alguém de fora entrar numa sala, ver a tela de outra pessoa, descobrir um IP que não devia, travar
o app de outra pessoa ou rodar algo no PC dela? **Não abra uma issue pública.** Use o aviso privado do GitHub: aba
[**Security**](https://github.com/ggekkos/espiadinha-releases/security) deste repositório → **Report a vulnerability**.

Conte o que acontece, como repetir e qual versão você usa. É um projeto pessoal e gratuito, mantido no tempo livre:
não há prazo garantido de resposta, mas todo aviso é lido.

## Reporting a security problem
Found a way for an outsider to join a room, see someone else's screen, learn an IP address they shouldn't, crash
someone else's app or run something on their PC? **Please don't open a public issue.** Use GitHub's private
reporting: this repository's [**Security**](https://github.com/ggekkos/espiadinha-releases/security) tab → **Report a vulnerability**.

Describe what happens, how to reproduce it and which version you use. This is a free personal project maintained in
spare time: there's no guaranteed response time, but every report is read.

## Escopo / Scope
- O app (Windows e Linux) e o protocolo entre os apps. / The app (Windows and Linux) and the protocol between apps.
- Fora do escopo: o servidor público do PeerJS e os servidores STUN (são de terceiros), e o fato já documentado de
  que quem está na mesma sala vê o IP dos outros. / Out of scope: the public PeerJS server and the STUN servers
  (third parties), and the documented fact that people in the same room see each other's IP addresses.
- Versões suportadas: só a mais nova. / Supported versions: only the latest one.
